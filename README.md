# Chitral Climate Analysis Using Python

## Project Overview
This project explores historical climate patterns in Chitral, Pakistan, using Python and Jupyter Notebook.

## Objectives
- Collect historical climate data.
- Explore daily temperature and precipitation.
- Calculate annual mean temperature.
- Calculate annual precipitation.
- Visualize climate patterns using Python.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Open-Meteo API

## Study Area
Chitral, Khyber Pakhtunkhwa, Pakistan.

## Data Source
Open-Meteo Historical Weather API.

## Project Status
Initial development: climate data collection, data exploration, annual temperature calculations and temperature visualization.

More climate analysis will be added as the project develops.
